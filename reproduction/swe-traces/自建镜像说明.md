## 为什么可以共用

```text
你自己的 Ubuntu + Conda 基础镜像
    └── 按 Python 和依赖配方分组的共享依赖层
            └── 每题指定 Git 提交的代码层
                    └── 每次运行的新临时容器
```

27 是按同一仓库、Python 版本、官方环境安装命令完全相同计算的候选组数，不是已经创建了 27 个环境，也不保证只需要 27 次构建。任务自己的预安装、编译和测试步骤仍须分别验证。未按结果筛题，100 题及其执行顺序没有改变。
